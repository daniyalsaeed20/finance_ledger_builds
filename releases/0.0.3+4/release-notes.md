# Release Notes

## Version 0.0.3 (Build 4)

Feature release focused on loans tracking, category taxonomy refresh, and Home analytics UX.

### Changed in this release

- Added a new Loans module with give/take/repay/recover flows, overview tracking, and Home loans banner entry points.
- Updated category taxonomy, including Charity/Zakat-related category adjustments and system category alignment.
- Replaced Home week/month range chips with a custom date-range selector for clearer analytics filtering.
- Refreshed Home KPI presentation with a carousel-based KPI surface and improved sparkline/series visuals.
- Aligned architecture and product docs with the shipped loans, category, and Home analytics behavior.

### Notes

- This build introduces loans as a first-class money-flow feature alongside existing budget and savings tracking.
- Home analytics now emphasizes flexible date ranges and carousel KPI browsing instead of fixed week/month chips.
- This build is compatible with `0.0.2+3`.
